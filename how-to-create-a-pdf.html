How to Create a PDF on Any Device

Digital Life · Updated 23 November 2026 · Takes about 2 minutes · Works on: Windows, Mac, Android, Google Docs

A PDF looks the same on every device, which makes it perfect for sharing documents, forms and printables. Here are the quickest ways to make one, no special software needed.

Before you start, you will need:
  • The document, page or file you want to turn into a PDF
  • An up-to-date browser or app (menu names can differ slightly between versions)

Method 1: Windows (any app with Print)

  1. Open your file. Open the document or web page you want to save.
  2. Open Print. Press Ctrl + P.
  3. Choose the PDF printer. In the printer list, select Microsoft Print to PDF (in Chrome, choose Save as PDF).
  4. Save. Click Print or Save, name the file and pick a folder.

Method 2: Mac

  1. Open your file and press Command + P.
  2. Open the PDF menu. Click the PDF button at the bottom-left of the print window.
  3. Save as PDF. Choose Save as PDF, name the file and click Save.

Method 3: Google Docs

  1. Open your document in Google Docs.
  2. Download as PDF. Tap File, then Download, then PDF Document (.pdf).
  3. Find the file. It saves to your Downloads folder.

Method 4: Android phone (web pages and files)

  1. Open the page in Chrome.
  2. Open the menu. Tap the three dots, then Share, then Print.
  3. Choose PDF. At the top, choose Save as PDF.
  4. Save. Tap the PDF button, then pick where to save the file.

Troubleshooting

The PDF is cut off or the layout looks wrong

In the print window, check the paper size (A4 or Letter) and set margins to Default. Turn off "Headers and footers" if you don't want them.

The file is too large to email

Reduce the size of any images in your document before saving, or send a link to the file instead of attaching it.

Tips

  • Give files clear names, such as weekly-meal-planner.pdf.
  • Check the PDF opens correctly before you share it.
  • Use PDF for finished documents. Keep the original file if you may need to edit it later.
